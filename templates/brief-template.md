Заполняется ДО кода. Пятнадцать минут здесь экономят день переделки потом.

## 1. Какие документы автоматизируем

Не «договоры вообще», а список. По каждому - есть ли реальный подписанный
эталон.

| Документ | Эталон есть? | Сколько выпускаю в месяц | Больно потому что |
|---|---|---|---|
| напр. Договор оказания услуг | да, 3 шт. | 8-10 | вбиваю реквизиты руками |
| | | | |

> Начинай с одного - самого частого. Второй добавится за вечер, когда первый
> заработает.
