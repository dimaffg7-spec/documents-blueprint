# База контрагентов (пример)

Скопируй в `config/contractors.md` и заполняй своими. Реальный файл — в
`.gitignore`: он содержит банковские реквизиты третьих лиц.

Формат: раздел `## Название` + строки `- Метка: значение`. Метки должны совпадать
со словарём `FIELD_LABELS` в `requisites.py` — иначе строка молча не прочитается.
`Алиасы` — дополнительные имена для поиска (сокращения, латиница, внутреннее прозвище).
